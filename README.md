## 🛠️ What I Engineer

I think **outside the box** to construct custom engines, desktop clients, and backend automations that eliminate manual labor and simplify complex software workflows.

* ⚙️ **Custom Engine Architecture:** Building fast, dedicated search engines, dynamic web scrapers, and data parsers from scratch.
* 🖥️ **Desktop Applications:** Engineering native cross-platform desktop tools and interfaces powered by **Electron**.
* 🤖 **Intelligent Automations & Bots:** Creating background workers and bots designed to execute repetitive multi-step jobs in seconds.
* 🔌 **API Systems & Webhooks:** Designing, fetching, and consuming high-throughput REST APIs, dynamic endpoints, and JSON streams.
